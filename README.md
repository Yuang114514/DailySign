# DailySign

Minecraft服务端签到插件，但是数据包

可以在支持原版数据包的服务端上运行的签到插件

# 功能

- 每日提醒玩家签到

- 首次签到奖励附魔金苹果

- 非首次签到奖励金苹果

- 完（fei）善（gan）的成就系统

- 一键恢复出厂设置

- 基于/schedule的自动复位

- 支持1.20.2+以上的Minecraft版本
